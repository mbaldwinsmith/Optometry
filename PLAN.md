# Optometry Report Generator
See Audiology Report Generator for ideas on architecture and implementation:

* Generates detailed care home and patient reports
* Patient details: ID (taken from Blink), First Name, Surname, DOB, Care Home, Post Code
* Toggle for NHS funded or Privately funded
* Last Full Examination
* Next Full Examination (+ 2 years)
* Example eye record:
Spex Rx:, SPH, CYL, Axis, Prism, Near Add, Near Prism, Int Add, Int Prism, PD
Right Eye, +0.50, -0.75, 180, -, +2.50, -, -, -,
Left Eye, +0.50, -0.75, 90, -, +2.50, -, -, -,
* Text based description of eye results, suitable for a patient with mild dementia, their family, and careworkers.
